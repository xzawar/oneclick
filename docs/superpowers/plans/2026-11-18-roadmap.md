# One Click MVP Roadmap

> Master plan. Each phase gets its own detailed plan file (`YYYY-MM-DD-phaseN-<name>.md`) written right before it starts, so plans use real interfaces from earlier phases. Only Phase 1 is detailed now.

**Spec:** `docs/PLAN.md`, `docs/AGENTS.md`, `docs/DESIGN.md`, `docs/GLOSSARY.md`, `docs/SETUP.md` · **Gaps/defaults:** `docs/SPEC_GAPS.md`

**Order rationale:** backend first — all money/business rules are server-side, so the API contract must exist before Android screens bind to it. Android track starts after Phase 1 against the live dev API.

## Phases

| Phase | Name | Features | Exit test |
|---|---|---|---|
| 0 | Repo, docs, agent skills | — | ✅ done (this commit) |
| 1 | Backend foundation | scaffold, env, migrations (all tables), auth (F01 server), users/me, mode guard | `npm test` green; `POST /api/auth/firebase` → JWT; `GET /api/users/me` |
| 2 | Money core | F20 wallet, manual top-up + admin approve, F17 escrow, F18 commission, F21 withdrawal, F19 cash fee | concurrent double-spend test fails to overdraw; replayed TID rejected |
| 3 | Providers & discovery | F03/F38 categories, F02/F25 provider signup + R2 private uploads + verification, F26 online toggle, F04/F05 nearby map (Redis GEO + PostGIS fallback) | provider below Rs.200 cannot go online; unverified never in `/nearby` |
| 4 | Booking lifecycle & real-time | F10 instant+scheduled, F11 negotiation, accept/reject/30s timeout, status flow, F33 photo proof, F32 confirm, F13 cancel, Socket.io rooms + Redis adapter, F08 FCM, F36 tracking | full booking e2e via `inject()` + socket client; escrow moves exactly once |
| 5 | Comms & safety | F07 Agora token, chat, F30 SOS + emergency contacts + live share, F34 disputes, F35 block/report (3+ auto-flag) | SOS reaches admin socket <2s; blocked user absent from nearby + cannot call |
| 6 | Admin dashboard (Next.js) | F37 live map, verifications, top-ups, withdrawals, disputes, stats; F31; F38 UI | admin approves top-up end-to-end; IP outside allowlist → 403 |
| A1 | Android shell | theme tokens, nav graph, Hilt, Retrofit, auth (Google Sign-In → JWT), mode toggle | sign in on device, toggle mode |
| A2 | Android customer | map + pins + filter, provider card, booking create, wallet + top-up upload | book a provider against dev API |
| A3 | Android provider | signup steps + CNIC + CameraX selfie, go online, location FGS, job popup (FCM full-screen), active job, photo proof | complete booking as provider |
| A4 | Android real-time & safety | tracking, chat, Agora call, SOS long-press, dispute, block/report, reconnect banner, Urdu RTL | two devices run a full job |
| 7 | Launch hardening | VPS (Ubuntu 24.04), Nginx+TLS, PM2, backups→R2, monitoring, rate limits, SBP legal, Play Store listing | staging soak 1 week; beta: Electrician + Plumber in DHA, Gulberg, Johar Town |

Parallelism: A1 can start after Phase 1. A2 needs Phases 2–3, A3 needs 3–4, A4 needs 4–5. Phase 6 can run alongside A-track.
